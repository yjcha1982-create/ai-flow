# 게시판 Flow 기반 개발 요청

첨부한 파일을 기준으로 게시판 프로젝트를 구현해 주세요.

- Flow 규격: `docs/FLOW_SPEC.md`
- 승인된 프로젝트: `samples/board-with-comments.flow.json`

## 작업 원칙

1. JSON의 Box와 관계를 임의로 삭제하거나 의미를 변경하지 않습니다.
2. 최상위 Flow와 내부 Flow의 순서, 분기, 입력, 출력을 준수합니다.
3. `approved` 또는 `ready` 상태인 Box를 구현 대상으로 봅니다.
4. 게시글 목록, 상세 읽기, 작성, 수정 기능을 구현합니다.
5. 댓글과 대댓글을 구현하며 대댓글 깊이는 한 단계만 허용합니다.
6. 게시글 수정은 작성자만 가능하게 합니다.
7. 입력 검증과 없는 게시글, 권한 오류를 처리합니다.
8. 각 Box의 완료 조건을 테스트합니다.

## 결과 보고 형식

작업 완료 후 다음 내용을 보고해 주세요.

```text
[구현 결과]
- 완료된 Flow:
- 완료된 Box:
- 차단 또는 실패한 Box:

[변경 파일]
- 파일 경로: 변경 내용

[테스트]
- 실행 명령:
- 통과 결과:
- 실패 결과:

[Flow 변경 제안]
- 필요한 경우에만 이유와 수정 JSON을 제안
```

Flow에 기술 선택이 명시되지 않았다면 기존 프로젝트의 기술과 패턴을 우선
사용하고, 새로운 기술이 반드시 필요할 때만 이유를 설명해 주세요.
