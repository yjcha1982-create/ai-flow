# AI Flow Studio 사용 가이드

## 1. 기본 작업 방식

권장 순서는 다음과 같습니다.

```text
요구사항 작성
→ AI에게 Flow 생성 요청
→ 생성된 JSON 적용
→ 사람이 구조와 규칙 검토
→ Box 상태 승인
→ Flow 기반 개발 요청
→ 결과와 테스트 기록
```

## 2. Box 만들기

상단의 `Box 추가`를 누르면 현재 Flow에 새 Box가 생성됩니다.

Box를 선택하면 우측에서 다음 항목을 편집할 수 있습니다.

- 제목
- 변경 가능한 Box 타입
- 실행 상태
- 설명
- AI 프롬프트
- 완료 조건
- 기대 산출물
- 실행 기록

프롬프트는 AI에게 무엇을 수행할지 알려주고, 완료 조건은 작업을 완료했다고
판단할 검증 기준을 제공합니다.

## 3. 내부 Flow 만들기

큰 Box를 선택한 뒤 `Flow 만들기`를 누르면 내부 Flow가 생성됩니다.

- 좌측 탐색기에 하위 Flow가 나타납니다.
- Box를 더블클릭해도 기존 하위 Flow로 이동할 수 있습니다.
- 중앙 상단 경로를 눌러 상위 Flow로 돌아갑니다.
- Box에는 프롬프트와 하위 Flow가 동시에 존재할 수 있습니다.

상위 Box의 프롬프트는 목적과 제약을 설명하고, 하위 Flow는 구체적인 순서와
구조를 설명하는 용도로 사용하는 것이 좋습니다.

## 4. 관계 만들기

Box 오른쪽 연결점을 끌어 다른 Box 왼쪽 연결점에 놓습니다.

관계를 선택하면 우측에서 타입, 라벨, 설명, 조건, 프롬프트를 수정할 수
있습니다. 타입을 변경하면 선의 색상과 패턴도 즉시 바뀝니다.

- 실행 순서: `sequence`
- 선행 결과 필요: `dependency`
- 데이터 전달: `data`
- 조건부 실행: `condition`
- 이벤트 시작: `event`
- 문맥 참조: `reference`

## 5. 규칙 검사

좌측 아래에서 전체 프로젝트의 오류와 경고 수를 확인할 수 있습니다.

상단 `AI 작업`을 열고 `규칙 검사` 탭을 선택하면 각 문제의 Flow ID와 요소
ID를 볼 수 있습니다.

대표적인 오류:

- 제목 없는 Box
- 프롬프트와 하위 Flow가 모두 없는 Box
- 조건이 없는 조건 관계
- 존재하지 않는 Box를 가리키는 관계
- 허용되지 않은 타입

## 6. AI에게 Flow 생성 요청

1. 상단 `AI 작업`을 엽니다.
2. `Flow 생성` 탭에서 요구사항을 작성합니다.
3. 아래 생성 프롬프트를 복사해 사용하는 AI에 전달합니다.
4. AI가 반환한 전체 프로젝트 JSON을 응답 입력란에 붙여넣습니다.
5. `AI Flow JSON 검증 후 적용`을 누릅니다.

앱은 JSON 문법과 Flow 규칙을 검사합니다. 오류가 있으면 기존 프로젝트를
보존하고 적용하지 않습니다.

실제 AI API를 연결할 때도 이 생성 프롬프트와 검증 함수를 그대로 사용할 수
있습니다.

## 7. Flow로 개발 요청

1. 실행할 Flow를 좌측 탐색기에서 선택합니다.
2. 실행할 Box의 상태를 `승인` 또는 `실행 대기`로 변경합니다.
3. 완료 조건과 기대 산출물을 작성합니다.
4. `AI 작업 → 개발 실행`에서 프롬프트를 복사합니다.
5. 코드 작업이 가능한 AI 에이전트에 전달합니다.

개발 에이전트는 관계 순서와 조건을 따라야 하며 작업 결과를 다음 형태로
돌려주는 것이 좋습니다.

- 변경된 Box 상태
- 변경 파일 목록
- 실행한 테스트와 결과
- 생성된 산출물
- 실패 또는 차단 사유
- 필요한 Flow 수정안

## 8. 저장과 공유

- `저장`: 전체 계층을 브라우저 `localStorage`에 저장합니다.
- `불러오기`: 마지막 저장 프로젝트를 복원합니다.
- `프로젝트 복사`: 규칙과 모든 하위 Flow를 포함한 JSON을 복사합니다.
- `JSON` 탭: 현재 프로젝트 전체 규격을 확인합니다.

저장 키는 `ai-flow-project`입니다.

## 9. 현재 범위

현재 버전은 AI API를 직접 호출하지 않습니다. 생성 및 실행 프롬프트를
복사해 외부 AI와 왕복하며, 반환된 Flow JSON은 앱에서 검증 후 적용합니다.

다음 단계에서 Tauri/Rust 또는 서버를 연결하면 아래 기능을 추가할 수
있습니다.

- AI 모델 직접 호출
- 저장소 파일 읽기와 코드 수정
- Box별 실행 큐
- 테스트 프로세스 실행
- Git 커밋과 변경 파일 자동 연결
- 실행 로그와 승인 이력 저장
