# AI Flow Studio 사용 가이드

## 생각하는 방법

개발 구성요소를 먼저 생각하지 말고 다음 두 질문으로 시작합니다.

1. 이 Box는 무슨 동작을 하는가?
2. 동작이 끝난 뒤 Flow는 어떻게 이동하는가?

예:

```text
[매일 오전 9시] 스케줄
        ↓ 흐르기
[새 주문 확인] 기능
        ↓ 흐르기
[주문이 있는가?] 조건
        ↓ 있음
[담당자에게 전달] 중계
        ↓ 보내고 끝
[알림 시스템]
```

## Box 사용법

### 기능

입력을 받아 결과를 만드는 가장 일반적인 Box입니다.

```text
주문 정보 → [주문 저장] → 주문 ID
```

입력과 출력, AI 프롬프트를 작성합니다.

### 중계

받은 정보를 여러 사람이나 시스템에 전달할 때 사용합니다.

```text
                  → [사용자 알림]
[결과 중계] ─────→ [관리자 알림]
                  → [로그 저장]
```

### 조건

판단 결과에 따라 다른 길로 이동할 때 사용합니다. `판단 규칙`에 기준을
작성하고 각 관계 라벨에 `있음`, `없음`, `성공`, `실패`처럼 결과를 적습니다.

### 반복

내부 작업이나 하위 Flow를 여러 번 수행할 때 사용합니다. 횟수, 주기,
멈추는 조건을 `반복 규칙`에 작성합니다.

### 스케줄

특정 시간이나 주기로 Flow를 시작할 때 사용합니다.

예: `매일 오전 9시`, `매주 월요일`, `5분마다`

### Flow

복잡한 Box 내부를 더 자세히 설계할 때 사용합니다. Box를 선택하고
`Flow 만들기`를 누르거나 좌측 탐색기의 `+ Flow`를 사용합니다.

### 시작과 종료

Flow의 진입점과 끝을 명확하게 표시할 때 사용합니다.

## 관계 사용법

- `흐르기`: 앞 동작이 끝나면 다음으로 갑니다.
- `요청·응답`: 갔다가 결과를 받아 돌아옵니다.
- `보내고 끝`: 전달한 뒤 현재 Flow는 끝납니다.
- `반복 요청`: 응답이나 조건을 확인하며 다시 요청합니다.
- `신호`: 실행만 시키고 응답을 기다리지 않습니다.
- `참조`: 이동하지 않고 정보나 규칙만 참고합니다.

## AI와 테스트하기

### 요구사항을 Flow로 변환

1. `AI 작업 → Flow 생성`을 엽니다.
2. 자연어 요구사항을 입력합니다.
3. 생성 프롬프트를 AI에 전달합니다.
4. AI가 반환한 프로젝트 JSON을 붙여넣습니다.
5. `AI Flow JSON 검증 후 적용`을 누릅니다.

이미 `.json` 파일이 있다면 `JSON 파일 열기`로 직접 불러올 수 있습니다.

저장소의 게시판 샘플은 `samples/board-with-comments.flow.json`입니다.

### Flow로 작업 요청

1. 사람이 Box와 관계를 검토합니다.
2. 실행할 Box 상태를 `승인` 또는 `실행 대기`로 변경합니다.
3. `AI 작업 → 개발 실행` 프롬프트를 복사합니다.
4. 프로젝트 JSON과 함께 작업 가능한 AI에 전달합니다.

AI는 Box의 입력과 출력을 기록하고 관계의 이동 방식에 따라 작업해야 합니다.

## 저장

- `저장`: 브라우저에 전체 프로젝트를 저장합니다.
- `불러오기`: 저장된 프로젝트를 복원하고 구 규격을 자동 변환합니다.
- `프로젝트 복사`: 모든 Flow와 규칙이 포함된 JSON을 복사합니다.

저장 키는 `ai-flow-project`입니다.
